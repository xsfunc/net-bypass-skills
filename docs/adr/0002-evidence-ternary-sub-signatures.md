# Evidence ternary with sub-signatures inside community-observed

The source files self-tag with a richer taxonomy than the three-skill convention (`verified`/`community-observed`/`hypothesis`): a 4-tier "honest disclaimer" (solid / illustrative / with-caveat / corrected) and per-claim provenance ("reverse-engineering, single researcher", "community-snapshot", "reproducible"). Rather than introduce a 4th tag (which would break consistency with the three already-shipped skills), `community-observed` carries a clarifying sub-signature naming the source class — `reverse-engineering, multi-source attested` for the Siberian model itself, `snapshot June-2026, operator-variable` for its numeric thresholds — so a reproducible model is distinguished from brittle constants without inflating the tag set. `verified` is reserved for pipeline-solid facts (TTL 128/64, JA3 formula, ASN numbers, RST/drop/throttle); `hypothesis` for the report-and-ask tier (eternal-h2/h3 mechanism, SNI↔IP mismatch as part of the scheme, statistical morphing as working defence, TLS-in-TLS round-trip as a separate vector).
